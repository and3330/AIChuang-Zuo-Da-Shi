Quick Start - Model Services
更新时间： 2025年5月14日 16:03:48首次发布时间： 2025年1月24日 14:49:24
This guide provides step-by-step instructions to configure your environment and invoke AI model services using our SDK, enabling seamless integration of model capabilities into your applications.

1. Obtaining and Configuring API Key
Your API key authenticates access to model services. Never expose it publicly.

Create API Key
Navigate to API Key Management.
Click Create API Key button.
Enter a name and click Create.
Image

tip

Store API keys securely (e.g., environment variables).Avoid hardcoding keys in source files.
For authentication details, see Access key.

Configure API Key to environment variables
macOS | Linux | Windows

macOS

Set temporary environment variables
If you want to use the API Key environment variables only in the current session:
Open a terminal and run the following command, replacing <YOUR_ARK_API_KEY> with your actual key.

export ARK_API_KEY="<YOUR_ARK_API_KEY>"  # Set key
echo $ARK_API_KEY                        # Verify

Set permanent environment variables
To apply the API Key to all new sessions for the current user:

Determine your default shell by running:
echo $SHELL
/bin/zsh: Zsh (Z shell) is the default.
/bin/bash: Bash is the default.

Zsh
Append the environment variable to ~/.zshrc.

echo "export ARK_API_KEY='<YOUR_ARK_API_KEY>'" >> ~/.zshrc && source ~/.zshrc
Verify the environment variable is set.

echo $ARK_API_KEY

Bash
Append the environment variable to ~/.bash_profile.

echo "export ARK_API_KEY='<YOUR_KEY>'" >> ~/.bash_profile && source ~/.bash_profile
Verify the environment variable is set.

echo $ARK_API_KEY

Linux

Set temporary environment variables
If you only want to use the environment variables in the current session, you can add temporary environment variables.

Open a terminal and run:
export ARK_API_KEY="<YOUR_ARK_API_KEY>"  # Set key
echo $ARK_API_KEY                        # Verify

Set permanent environment variables
If you want API Key environment variables to take effect in all new sessions for the current user, you can add permanent environment variables.

Append the environment variable to ~/.bashrc:
echo "export ARK_API_KEY='<YOUR_ARK_API_KEY>'" >> ~/.bashrc && source ~/.bashrc
Verify in a new terminal:
echo $ARK_API_KEY

Windows

Set temporary environment variables
If you only want to use the environment variables in the current session, you can add temporary environment variables.

Open CMD or PowerShell and run, replacing <YOUR_ARK_API_KEY>.

set ARK_API_KEY="YOUR_KEY"       # CMD 
$env:ARK_API_KEY = "YOUR_KEY"    # PowerShell
Verify the setting:

echo %ARK_API_KEY%    # CMD
echo $env:ARK_API_KEY # PowerShell

Set permanent environment variables
To ensure your API Key persists across all new terminal sessions for the current user, configure permanent environment variables using the following commands:

CMD
setx ARK_API_KEY "YOUR_API_KEY"

PowerShell
[Environment]::SetEnvironmentVariable("ARK_API_KEY", "YOUR_API_KEY", [EnvironmentVariableTarget]::User)

Verification
Run the appropriate command below to confirm the setup:

echo %ARK_API_KEY%    # CMD
echo $env:ARK_API_KEY # PowerShell
If your API Key is displayed, the configuration is successful.

2. Get Model ID
You can quickly invoke the model using its Model ID:

Select a model from the Model List and obtain its Model ID.
Activate the corresponding model service on the Model Activation management page.
Tip: Use Endpoint IDs for advanced features like rate limiting and monitoring. See Inference Endpoint for details.

3. Configure the environment and initiate a call
Python | Curl | Go | Java
Choose a programming language to invoke the model inference service based on your needs.

Python

Python installation
Ensure Python 3.7 or higher is installed:

Check the installed version:
python -V  # or python3 -V if needed  
If not installed or outdated, refer to the Python installation tutorial and select a version ≥ 3.7.

BytePlus Python SDK
jump to use OpenAI SDK

Install the BytePlus Python SDK.

pip install byteplus-python-sdk-v2
Create ark_example.py with the following code, replacing <MODEL>.

import os
from byteplussdkarkruntime import Ark
# Get API Key
client = Ark(api_key=os.environ.get("ARK_API_KEY"))
completion = client.chat.completions.create(
    # Replace <MODEL> with Model ID / your inference endpoint ID 
    model="<MODEL>",
    messages=[
        {"role": "user", "content": "hello"}
    ]
)
print(completion.choices[0].message)
Run the script:

python ark_example.py  
After running, you can view the response of the model call in the terminal, and at this point, you have completed your first model service call on the Ark Platform.


OpenAI SDK
Jump to use Ark Python SDK.

Install the OpenAI SDK. You can install/upgrade the Ark OpenAI SDK by entering the following command in a terminal.

pip install -U openai
Create ark_example.py with the following code, replacing <MODEL>.

import os
from openai import OpenAI

client = OpenAI(
    # Get API Key
    api_key=os.environ.get("ARK_API_KEY"), 
    base_url="https://ark.ap-southeast.bytepluses.com/api/v3",
    )
completion = client.chat.completions.create(
    # Replace <MODEL> with Model ID / your inference endpoint ID

    ]

print(completion.choices[0].message)
In a terminal, run the code using the following command. You can see the return result of the model call in the terminal later, and you have completed your first Ark platform model service call.

python ark_example.py

Curl
You can directly invoke the Ark model service via HTTP. In a terminal, copy and execute the following command, replacing <MODEL> with your actual endpoint ID. After a short wait, the model's response will appear in the terminal, confirming your first successful call to the Ark Platform model service.

curl https://ark.ap-southeast.bytepluses.com/api/v3/chat/completions \

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -d '{
    "model": "<MODEL>",
    "messages": [
        {"role": "user","content": "hello"}
    ]
  }'
If an error code {"error":{"code":"AuthenticationError","message":"The API key or AK/SK in the request is missing or invalid. requestId: 0217***"}} is returned, this indicates that the API Key is not correctly configured in the environment variables. Replace $ARK_API_KEY in your environment with your actual Ark API Key, and run the command again.

Go
Check and install the Go version, the Go version needs to be 1.18 or above.

go version
You can visit Go language official website to download the appropriate version of Go for your operating system. Make sure to select version 1.18 or above.

Install the Ark Go SDK.
The ModelArk Go SDK is managed using go mod. If the local project does not have go mod initialized, you can run the following command to initialize go mod. Replace <YOUR_PROJECT_NAME> with your actual project name.

# Open a terminal in the ark-example folder and run the command go mod init ark-example
go mod init <YOUR_PROJECT_NAME>
Create a main.go file and copy the following code into the file, replacing .

package main

import (
    "context"
    "fmt"
    "os"
    "github.com/byteplus-sdk/byteplus-go-sdk-v2/service/arkruntime"
    "github.com/byteplus-sdk/byteplus-go-sdk-v2/service/arkruntime/model"
    "github.com/byteplus-sdk/byteplus-go-sdk-v2/byteplus"
)

func main() {
    client := arkruntime.NewClientWithApiKey(
        // Get ARK_API_KEY from environment variables through os.Getenv
        os.Getenv("ARK_API_KEY"),

    )
    // Create a context, usually used to pass context information of requests, such as timeouts, cancellations, etc.
    ctx := context.Background()
    // Build a chat completion request, set the model and message content of the request
    req := model.ChatCompletionRequest{
        // Replace <MODEL> with Model ID / your inference endpoint ID 
        Model: "<MODEL>",
        Messages: []*model.ChatCompletionMessage{
            {
                // The role of the message is the user
                Role: model.ChatMessageRoleUser,
                Content: &model.ChatCompletionMessageContent{
                    StringValue: byteplus.String("hello"),
                },
            },
        },
    }

    // Send the chat completion request, store the result in resp, and store the possible error in err
    resp, err := client.CreateChatCompletion(ctx, req)
    if err!= nil {
        // If an error occurs, print the error message and terminate the program
        fmt.Printf("standard chat error: %v\n", err)
        return
    }
    // Print the response result of the chat completion request
    fmt.Println(*resp.Choices[0].Message.Content.StringValue)
}
In the terminal, update the project's dependencies with the following command.

go mod tidy
In the terminal, run the code using the following command. You can see the return result of the model call in the terminal later. This completes your first Ark platform model service call.

go run main.go

Java
Check the Java environment version. The Java version must be 1.8 or above.

java -version
If Java is not installed or the version does not meet the requirements, you can visit the Oracle official website to download and install the Java version suitable for your operating system. Please make sure to select version 1.8 or above.

Install ModelArk Java JDK.
The Java SDK supports installation via Maven and Gradle.

Installation via Maven: Add the following dependency configuration to the project's pom.xml file.
...
<dependency>
    <groupId>com.byteplus</groupId>
    <artifactId>byteplus-java-sdk-v2-ark-runtime</artifactId>
    <version>LATEST</version>
</dependency>
...
Open a terminal and go to the project root directory, and run the following command to install the dependencies.

mvn clean install
Install via Gradle: In the project's build.gradle file, add the following dependency in the dependencies section.
implementation 'com.byteplus:byteplus-java-sdk-v2-ark-runtime:LATEST'
Copy the following sample code into your project and replace your inference Endpoint ID

package com.ark.example;

import com.byteplus.ark.runtime.model.completion.chat.ChatCompletionRequest;
import com.byteplus.ark.runtime.model.completion.chat.ChatMessage;
import com.byteplus.ark.runtime.model.completion.chat.ChatMessageRole;
import com.byteplus.ark.runtime.service.ArkService;

import java.util.ArrayList;
import java.util.List;

/**
 * This is an example class that shows how to use ArkService to complete the chat function.
 */
public class ChatCompletionsExample {
    public static void main(String[] args) {
        // Get the API key from the environment variable
        String apiKey = System.getenv("ARK_API_KEY");

        // Create an ArkService instance
        ArkService arkService = ArkService.builder().apiKey(apiKey).build();

        // Initialize the message list
        List < ChatMessage > chatMessages = new ArrayList < > ();

        // Create user messages
        ChatMessage userMessage = ChatMessage.builder()
            .role(ChatMessageRole.USER) // Set the message role to user
            .content("Hello") // Set the message content
            .build();

        // Add the user message to the message list
        chatMessages.add(userMessage);

        // Create a chat completion request
        ChatCompletionRequest chatCompletionRequest = ChatCompletionRequest.builder()
            .model("<Model>") // Need to be replaced with Model ID /your inference Endpoint ID
            .messages(chatMessages) // Set the message list
            .build();

        // Send a chat completion request and print the response
        try {
            // Get the response and print the message content of each choice
            arkService.createChatCompletion(chatCompletionRequest)
                .getChoices()
                .forEach(choice - > System.out.println(choice.getMessage().getContent()));
        } catch (Exception e) {
            System.out.println("Request failed: " + e.getMessage());
        } finally {
            // Shut down the service executor
            arkService.shutdownExecutor();
        }
    }
}
Compile your Java project and run it. You can see the return result of the model call in the terminal after a while. This completes your first ModelArk platform model service call.
